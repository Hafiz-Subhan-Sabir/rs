Our work

Two projects that show how we build

These are real products we have shipped. One client name stays private until they ask us to share it. Hafiz Subhan managed both projects as Project Manager while also guiding the technical build.

1. Cloud enterprise web app Client name on request

A membership style web product for a growing business. Members can sign in, take courses, read content, and pay in GBP or USD based on location. We also set up roles so staff and members only see what they should see.

The work included system planning, AI assisted workflows, fast delivery through Cloudflare, course video in short segments, secure login, and a clear path for future blockchain features if the client wants them later.

  • Cloud ready structure that can grow with more users
  • Admin and member areas with proper access control
  • Payment checks and content tools in one place

2. Online quiz exam app with AI proctoring

An exam product for teachers and students. Teachers create timed quizzes. Students take one question at a time with a clear timer. The app watches for face presence on the webcam and notes if someone leaves the page or exits full screen.

Results and warning logs sit in one admin view, including screenshots when something looks off. It was built as a serious product, not a classroom demo.

  • Separate panels for teachers and students
  • Quiz builder and auto submit when time ends
  • Simple logs so staff can review what happened
